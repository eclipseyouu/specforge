# SRS: TechVault — система учёта IT-оборудования

## Роли
- Employee — сотрудник
- Manager — менеджер отдела
- Admin — администратор склада

## 20 требований
R-01..R-10 — функциональные
R-11..R-16 — исключения
R-17..R-20 — пограничные

## 12 бизнес-правил (5 с временем)
1. Штраф после 23:59:59 дня дедлайна
2. Штраф = days * rate * 1.5
3. Бронь истекает через 24ч
4. Переход в Maintenance при >1000ч
5. Одобрение менеджера за 48ч
6-12. Инварианты и ролевые ограничения

## 10 сущностей
Equipment, Employee, Reservation, IssueRecord, Fine, Department, Role, MaintenanceLog, Request, AuditLog
